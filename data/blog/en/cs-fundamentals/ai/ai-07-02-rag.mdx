# 1. RAG(Retrieval Augmented Generation)

Produces improved results by providing externally retrieved data together with the question or instruction

## 1. RAG process

### 1. Indexing

#### 1. Chunk splitting

Split documents into small units

##### Chunking strategies

###### 1. Fixed-size splitting

Simple, but risks breaking the context.

###### 2. Overlapping splitting

Overlaps part of adjacent [chunks](glossary:chunking) to preserve the continuity of context

###### 3. Paragraph/section-based splitting

Splits the document at paragraph boundaries and headers

###### 4. Recursive splitting

Splits in the order paragraph > sentence > word
Splits further when the size is exceeded

#### 2. Creating embedding vectors

##### Definition of an embedding vector

Converts text into a numeric vector while preserving meaning

Words with similar meanings are located close together in [vector space](glossary:vector-space)

```json
Example

"puppy" → [0.23, -0.87, 0.14, 0.56, 0.91, ...]
"dog" → [0.21, -0.83, 0.17, 0.52, 0.88, ...] ← similar
"car" → [0.91, 0.34, -0.67, 0.12, -0.44, ...] ← different
```

##### How the encoder creates embedding vectors

###### Terminology

1. [hidden state](glossary:hidden-state): the internal representation vector of each [token](glossary:token) that the [Transformer](glossary:transformer) creates reflecting context
2. [polling](glossary:pooling): a method of combining multiple [token](glossary:token) [hidden states](glossary:hidden-state) into one fixed-size vector
3. [RoBERTa](glossary:roberta): a [BERT](glossary:bert)-family [Transformer](glossary:transformer) [encoder](glossary:encoder); splits the input sentence into [tokens](glossary:token) and turns each [token](glossary:token) into a context-aware vector.
4. [CLS](glossary:cls-token)(Classification):
   - A special [token](glossary:token) placed at the very start of a sentence in [BERT](glossary:bert)-family models
   - The [hidden state](glossary:hidden-state) of [CLS](glossary:cls-token) can be used as a vector representing the whole sentence.
5. [Mean Polling](glossary:mean-pooling): the average of all [token](glossary:token) vectors, used in [sentence-BERT](glossary:sentence-bert) (better performance)
6. [Max Polling](glossary:max-pooling): the maximum of each dimension, good for emphasizing features
7. [Polling](glossary:pooling) using the [CLS](glossary:cls-token) [token](glossary:token): uses the [CLS](glossary:cls-token) [token](glossary:token), which compresses the meaning of the whole sentence
8. [Bi-encoder](glossary:bi-encoder): two identical models each take a different sentence as input to learn similarity; used to build the [embedding](glossary:embedding) [vector DB](glossary:vector-database)
9. [Cross-encoder](glossary:cross-encoder): an [encoder](glossary:encoder) takes two sentences as input at the same time to learn similarity; used to select the candidates that match the query ([reranking](glossary:reranking))
   - Among the candidates roughly picked by the [Bi-encoder](glossary:bi-encoder), the [Cross-encoder](glossary:cross-encoder) picks again the ones that are truly relevant

###### Step flow

0. The [tokenizer](glossary:tokenization) turns the input text into [tokens](glossary:token).
1. The [Transformer](glossary:transformer) [encoder](glossary:encoder) produces a [hidden state](glossary:hidden-state) per [token](glossary:token).
2. To make a sentence/[chunk](glossary:chunking) [embedding](glossary:embedding), the per-token [hidden states](glossary:hidden-state) must be combined into one.
3. This combining method is [pooling](glossary:pooling).
4. [Pooling](glossary:pooling) options include [[CLS](glossary:cls-token)], [mean pooling](glossary:mean-pooling), [max pooling](glossary:max-pooling), using the last [token](glossary:token), etc.
5. In a [Bi-encoder](glossary:bi-encoder), these text vectors are created separately for the question and the documents, and their similarity is compared.
6. Generate fixed-size vectors and store them in the DB
7. In a [Cross-encoder](glossary:cross-encoder), the question and a document are fed in together to directly compute relevance scores for the vectors in the DB.
