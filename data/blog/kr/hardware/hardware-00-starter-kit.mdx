> 하드웨어를 취미로 시작하면서 쓰는 시리즈의 첫 글이다. 첫 물건은 휴대용 블루투스 스피커다. 이 글에는 무엇을 어떤 순서로 만들지, 시작하기 전에 무엇을 사고 어떤 도구를 익혀야 하는지 정리했다. 아직 아무것도 사지 않은 시점(2026년 11월 17일)에 쓴 글이라, 가격은 모두 이날 쇼핑몰에서 확인한 값이다.

## 1. 무엇을 만드나

폰에서 블루투스로 음악을 받아 스피커로 내보내는 휴대용 스피커다. 들어가는 부품은 크게 넷이다.

| 부품                    | 하는 일                                                                        |
| ----------------------- | ------------------------------------------------------------------------------ |
| ESP32 개발보드          | 폰에서 블루투스로 소리를 받는다. 이 위에서 내가 짠 펌웨어가 돈다               |
| I2S 앰프 보드           | ESP32가 보낸 디지털 소리 신호를 받아, 스피커를 울릴 만큼 키운다 (MAX98357A 등) |
| 스피커                  | 소리를 낸다                                                                    |
| 배터리와 충전·보호 회로 | 선 없이 들고 다니게 한다. 맨 마지막 단계에 붙인다                              |

ESP32는 **원조 ESP32**로 고른다. 폰에서 음악을 받는 블루투스 방식(Classic Bluetooth의 A2DP)은 원조 ESP32만 지원하고, 이름에 S3, C3 같은 글자가 붙은 후속 칩은 지원하지 않는다. 같은 원조 ESP32라도 모듈 이름 끝이 `U`인 것(WROOM-32U)은 외부 안테나를 따로 꽂아야 하므로, 보드에 안테나가 붙은 `E`나 `D` 모델을 고른다.

## 2. 진행 순서

| 단계 | 하는 일                                                                                       | 결과물                         |
| ---- | --------------------------------------------------------------------------------------------- | ------------------------------ |
| 1    | 브레드보드에 ESP32, 앰프 보드, 스피커를 꽂아 소리가 나는지 확인한다                           | 동작하는 시험 회로             |
| 2    | 같은 회로를 만능기판에 옮겨 납땜으로 고정한다. **첫 스피커는 이걸로 완성한다**                | 첫 완성품                      |
| 3    | KiCad로 회로도와 기판을 설계하고 PCB 공장에 주문한다. 무선 부분은 인증받은 모듈을 그대로 쓴다 | 녹색 PCB에 납땜한 두 번째 버전 |
| 4    | 파이썬으로 그리는 CAD(CadQuery)로 케이스를 설계하고 3D 출력 대행에 맡긴다                     | 케이스                         |
| 5    | 리튬 배터리와 보호 회로를 붙인다                                                              | 휴대용 완성품                  |

순서를 이렇게 정한 이유는 두 가지다. 회로가 맞는지 모르는 상태에서 기판부터 주문하면 틀린 기판에 돈을 쓰게 된다. 그리고 납땜을 처음 해 보는 손으로 처음 주문한 기판을 만지면 기판을 망치기 쉽다. 그래서 브레드보드로 회로를 확인하고, 만능기판으로 납땜을 익힌 다음 공장 PCB로 넘어간다. 3D 프린터는 비용이 꽤 들어서 처음에는 사지 않는다. 케이스는 출력 대행에 맡긴다. 파일을 올리면 뽑아서 보내 주는 온라인 대행을 기본으로 하고, 오프라인 출력소에도 한 번은 직접 가 본다. 오프라인 후보는 3D 프린터가 있는 충북Pro메이커센터인데, 학생이 어떤 조건으로 쓸 수 있는지는 아직 확인하지 않았다. 프린터는 나중에 산다. 배터리는 잘못 다루면 불이 날 수 있어서 회로가 다 안정된 뒤 마지막에 붙인다.

결과물은 물건마다 레포 하나에 모은다. 레포 안은 `firmware/`(펌웨어), `hardware/`(KiCad 파일), `enclosure/`(케이스), `docs/`로 나눈다.

## 3. 처음 보는 용어

| 용어               | 뜻                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 브레드보드         | 구멍이 뚫린 플라스틱 판. 안쪽 금속 띠가 줄 단위로 이어져 있어서 부품과 점퍼선을 꽂기만 하면 회로가 된다. 납땜이 없어서 고치기 쉽지만 흔들리면 빠진다 |
| PCB (인쇄회로기판) | 부품을 올리고 부품 사이를 구리 길로 이어 주는 판. 컴퓨터 메인보드, 폰, 이어폰 안에 다 들어 있다                                                      |
| 솔더 마스크        | PCB 위에 바르는 보호 코팅. 녹색이 흔할 뿐 검정, 빨강, 파랑도 있다. 구리가 산화되지 않게 하고, 납이 엉뚱한 길로 번지는 걸 막는다                      |
| 만능기판           | 구멍만 2.54mm 간격으로 뚫려 있고 길은 그려지지 않은 PCB. 연결은 납이나 전선으로 직접 잇는다                                                          |
| 풋프린트           | 부품마다 기판에 뚫을 구멍이나 패드의 모양. 틀리면 부품이 기판에 맞지 않는다                                                                          |
| 거버 파일          | PCB 공장에 보내는 도면 파일                                                                                                                          |
| 펌웨어             | 기계 안의 작은 칩 위에서 운영체제 없이(또는 아주 작은 운영체제 위에서) 도는 프로그램                                                                 |
| 임베디드           | 어떤 기계 안에 박혀서 그 기계 하나만 돌리는 컴퓨터, 또는 그걸 다루는 분야. 세탁기, 무선 이어폰, 자동차 제어기가 다 여기 속한다                       |
| I2S                | 칩끼리 디지털 소리를 주고받는 통신 방식. ESP32가 앰프 보드에 소리를 넘길 때 쓴다                                                                     |
| A2DP               | 블루투스로 음악을 보내는 규격. 폰과 블루투스 스피커가 이걸로 통한다                                                                                  |
| 플럭스             | 금속 표면의 산화막을 걷어내서 납이 잘 붙게 하는 약                                                                                                   |
| 솔더윅             | 구리 심지. 녹은 납에 대고 인두로 누르면 납을 빨아들인다. 핀 두 개를 납으로 붙여 버렸을 때 쓴다                                                       |

## 4. 살 것

처음 사는 건 부품이 아니라 **장비와 소모품**이다. 앰프 보드에 달린 핀헤더부터 직접 납땜해야 해서 1단계부터 인두가 필요하다.

아래 가격은 2026년 11월 17일에 각 상품 페이지에서 확인한 값이고, VAT를 포함했다. 판매처는 아직 확정하지 않았다. 가격비교 사이트에서도 찾아봤지만, 이런 소형 공구는 업소용 대용량(실납 1kg 같은)이나 해외 구매대행만 잡혀서 전자부품 전문 쇼핑몰을 기준으로 적었다.

인두를 고를 때 걸린 점이 둘 있다.

- Pinecil은 국내 가격비교 사이트에 해외 구매대행 상품만 있었고, 가격이 159,600~163,100원이었다. 공식몰 가격의 4배가 넘어서 공식몰 직구로 정했다.
- Pinecil은 **USB-C PD 45W 이상** 충전기를 꽂아야 제대로 달궈진다. 폰 충전기는 대개 15~25W라 느리다. 노트북 충전기면 거의 된다. 충전기는 집에 있는 걸 쓰기로 해서 목록에서 뺐다.

납은 처음엔 **유연납**(주석과 납이 섞인 것)으로 한다. 무연납보다 낮은 온도에서 녹고 잘 흘러서 다루기 쉽다. 대신 납이 들어 있으니 환기하고, 작업 뒤에는 손을 씻는다. 무연납으로 바꾸면 플럭스도 무연납용으로 바꿔야 한다.

## 5. 익힐 도구

캐드 하나만 알면 되는 일은 아니다. 단계마다 필요한 도구가 다르다.

나는 이 작업을 Claude Code(터미널에서 파일을 읽고 고치고 명령을 실행하는 AI 코딩 도구)와 같이 한다. 그래서 도구마다 Claude Code가 직접 다룰 수 있는지도 같이 적었다. 기준은 단순하다. 텍스트 파일과 명령줄(CLI)로 다룰 수 있는 도구는 Claude Code가 직접 쓰고, 마우스로 화면을 만져야 하거나 손으로 하는 일은 내가 한다.

| 표시 | 뜻                                                                   |
| ---- | -------------------------------------------------------------------- |
| ●    | Claude Code가 직접 한다 (파일 작성, 명령 실행, 결과 확인까지)        |
| ◐    | 일부만 한다 (파일 생성, 검사, 내보내기는 하고 화면 작업은 내가 한다) |
| ○    | 내가 한다 (손으로 하는 일, 결제). Claude Code는 설명과 확인만 돕는다 |

### 5.1 1단계: 브레드보드

| 익힐 것    | 내용                                                                                                               | Claude Code                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 회로 기초  | 전압, 전류, 저항의 관계(옴의 법칙)와 데이터시트에서 핀 번호와 전압 범위 찾는 법. 이게 없으면 회로도를 그릴 수 없다 | ◐ 데이터시트를 읽고 연결표를 만든다. 이해는 내가 한다                                |
| PlatformIO | 펌웨어 개발 환경. 코드 작성, ESP32용 컴파일, USB로 보드에 써 넣기(플래싱), 시리얼 모니터를 한곳에서 한다           | ● `pio run`으로 빌드, `pio run -t upload`로 업로드, `pio device monitor`로 로그 확인 |
| 멀티미터   | 도통 테스트와 전압 측정                                                                                            | ○ 무엇을 어디서 잴지는 Claude Code가 정해 준다                                       |
| 납땜       | 만능기판에 저항 다리를 꽂아 납땜하는 것부터 시작한다                                                               | ○                                                                                    |

펌웨어 개발 환경은 세 가지 중에 골랐다.

| 도구        | 특징                                                                            | 선택     |
| ----------- | ------------------------------------------------------------------------------- | -------- |
| Arduino IDE | 설치하고 버튼 몇 개로 바로 쓴다. 가장 쉽다                                      |          |
| PlatformIO  | 보드 종류, 라이브러리 버전, 업로드 설정이 `platformio.ini` 파일 하나에 들어간다 | **선택** |
| ESP-IDF     | 칩 제조사 공식 도구. 가장 세밀하게 다룰 수 있지만 설정할 것이 많다              |          |

PlatformIO를 고른 이유는 넷이다. 평소 쓰는 편집기(VS Code) 안에서 돌아서 도구가 늘지 않는다. 설정 파일을 레포에 커밋하면 윈도우와 맥 어디서든 같은 버전으로 빌드된다. 빌드와 업로드가 명령 하나라서 Claude Code가 코드를 고치고 바로 보드에 올려 로그까지 볼 수 있다. 같은 이유로 나중에 CI로 빌드 확인을 돌리기도 쉽다.

확인할 것이 하나 남아 있다. 블루투스로 음악을 받는 ESP32-A2DP 라이브러리는 ESP32 Arduino 코어 버전을 탄다. PlatformIO 공식 ESP32 플랫폼이 어느 코어 버전까지 지원하는지는 아직 확인하지 않았다. 보드를 받고 개발 환경을 만들 때 먼저 확인한다.

### 5.2 2~3단계: 만능기판과 공장 PCB

| 익힐 것              | 내용                                                                                    | Claude Code                                                                      |
| -------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 만능기판 배치도      | 어느 구멍에 어느 부품을 꽂고 어디를 이을지 그린 그림                                    | ● 연결표와 배치도를 만든다. 납땜은 ○                                             |
| KiCad 회로도         | 부품을 기호로 놓고 선으로 연결한다                                                      | ◐ KiCad 파일은 텍스트라 읽고 고칠 수 있다. 화면에서 다듬는 건 내가 한다          |
| KiCad PCB 배치       | 실제 판 위에 부품 자리(풋프린트)를 놓고 구리 길을 그린다                                | ◐ 부품 배치와 배선은 내가 화면에서 한다. Claude Code는 배치 기준과 검토를 돕는다 |
| DRC (설계 규칙 검사) | 선이 너무 가깝거나 끊긴 곳을 자동으로 찾는다                                            | ● `kicad-cli`로 검사를 돌리고 결과를 읽는다                                      |
| 주문 파일            | PCB 공장에 보낼 거버 파일, 부품까지 붙여 받을 때 필요한 BOM(부품 목록)과 부품 배치 파일 | ● `kicad-cli`로 뽑는다                                                           |
| PCB 공장 주문        | 파일을 올리고 옵션을 고르고 결제한다                                                    | ○ 결제는 내가 한다                                                               |

PCB를 꼭 공장에 맡겨야 하는 건 아니다. 만들 방법은 세 가지다.

| 방법                 | 장점                                     | 단점                                                         |
| -------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 만능기판에 직접 배선 | 공장 없이 하나만 만들 때 가장 현실적이다 | 선이 지저분하고 크기가 커져서 휴대용 케이스에 넣기 빡빡하다  |
| 집에서 동판 부식     | 바로 만들 수 있다                        | 약품 처리와 환기, 폐액 처리가 필요하고 보통 한 면짜리다      |
| 공장 주문            | 녹색 코팅까지 된 판이 온다               | 1~2주 걸리고 배송비가 든다. 회로가 틀리면 다시 주문해야 한다 |

첫 스피커는 만능기판으로 완성하고, 공장 주문은 그다음 버전으로 계획한다. 공장 주문 비용은 주문할 때 다시 확인한다.

### 5.3 4단계: 케이스

| 익힐 것                 | 내용                                                                                        | Claude Code                                 |
| ----------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------- |
| CadQuery                | 파이썬으로 3D 모양을 그리는 CAD                                                             | ● 파이썬 코드를 짜고 실행해서 모델을 만든다 |
| 기판과 케이스 맞춰 보기 | KiCad에서 기판을 3D 파일(STEP)로 뽑아 케이스 안에 넣어 보고, 나사 구멍과 USB 구멍을 맞춘다  | ● 기판 STEP 내보내기와 치수 비교            |
| 출력 파일               | 출력 대행에 보낼 STL 파일을 뽑는다                                                          | ● CadQuery에서 STL로 내보낸다               |
| 출력 대행 주문          | 온라인은 파일을 올리고 재질을 고르고 결제한다. 오프라인은 충북Pro메이커센터에 한 번 가 본다 | ○                                           |

코드로 그리는 CAD는 두 가지를 비교했다.

| 도구     | 특징                                                            | 선택     |
| -------- | --------------------------------------------------------------- | -------- |
| OpenSCAD | 전용 언어. 배우기 쉽다                                          |          |
| CadQuery | 파이썬 라이브러리. 둥근 모서리 같은 복잡한 모양을 다루기 편하다 | **선택** |

CadQuery를 고른 이유는 셋이다. 이미 쓰는 언어(파이썬)라 새 문법을 배울 필요가 없다. 치수를 변수로 두고 고칠 수 있고, 변경 내역을 Git으로 관리할 수 있다. 그리고 코드라서 Claude Code가 직접 짜고 고칠 수 있다. 마우스로 그리는 CAD였다면 이 부분은 전부 내 손으로 해야 했다.

모델을 프린터용 명령으로 바꾸는 프로그램(슬라이서)은 대행이 처리하므로 프린터를 살 때 익힌다.

### 5.4 5단계: 배터리

새 도구는 없다. 리튬 배터리 충전 보드와 보호 회로(과충전, 과방전, 단락을 막는 회로)를 이해하는 것이 전부다. 배선을 잘못하면 불이 날 수 있어서, 연결은 Claude Code와 같이 데이터시트로 확인하고 손으로 하는 작업은 내가 한다.

### 5.5 전 단계 공통

| 도구 | 내용                                                   | Claude Code |
| ---- | ------------------------------------------------------ | ----------- |
| Git  | 펌웨어, KiCad 파일, 케이스 코드를 한 레포에서 관리한다 | ●           |

정리하면 코드로 다루는 일(펌웨어, 케이스, 검사와 파일 내보내기)은 Claude Code가 직접 하고, 손으로 하는 일(납땜, 측정, 기판 배선)과 결제는 내가 한다.
