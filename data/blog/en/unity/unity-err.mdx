## 1. Click the Edit tab

## 2. Click Project Settings

## 3. Click Player

![Player Settings screen](/static/images/unity-err/player.png)

## 4. Go to Other settings

![Other Settings screen](/static/images/unity-err/other-setting.png)

## 5. In the Active Input Handling tab, change the value to both

![Active Input Handling settings screen](/static/images/unity-err/active-input.png)
