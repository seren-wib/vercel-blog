# CH3. data transmission (how to turn data into signals and send them)

## 1. Data transmission media

**Transmitter** ↔ **Transmission medium** ↔ **Receiver**

### 1-1 Types of transmission media

**Classified by whether the signal travels only inside a physical medium (cable)**
|Term|Examples|
|---|---|
|[Guided media](glossary:guided-media)| Twisted pair, Coaxial cable, Optical fiber|
|[Unguided media](glossary:unguided-media)| Propagation through air, vacuum, etc.|

### 1-2 Connection structure

**How the devices connected to the medium are arranged**

- [Direct link](glossary:direct-link): no devices between the transmitter and receiver other than amplifiers or repeaters
  - Amplifiers and repeaters are equipment that restores signal strength, so they are not counted as "intermediate devices"
- Point-to-Point: a [direct link](glossary:direct-link), with 2 devices sharing the medium
- Multi-point: more than two devices share the same medium

### 1-3 Transmission direction

**Which direction does the signal flow? Can it flow both ways at once?**

| Term                                | Simultaneous transmission | Bidirectional    | Example            |
| ----------------------------------- | ------------------------- | ---------------- | ------------------ |
| [Simplex](glossary:simplex)         | x                         | x (one-way)      | Radio broadcasting |
| [Half duplex](glossary:half-duplex) | x                         | O (taking turns) | Walkie-talkie      |
| [Full duplex](glossary:full-duplex) | O                         | O                | Telephone          |

### 1-4 4 factors to consider when designing/selecting a medium

| Factor                          | Effect                                                                                              |
| ------------------------------- | --------------------------------------------------------------------------------------------------- |
| [Bandwidth](glossary:bandwidth) | The wider the [frequency](glossary:frequency) range, the higher the [data rate](glossary:data-rate) |
| Transmission impairments        | Impairments such as [attenuation](glossary:attenuation) limit the distance                          |
| Interference                    | Overlapping [frequency](glossary:frequency) bands distort or cancel the signal                      |
| Number of receivers             | The more receivers, the more the signal is attenuated                                               |

- [attenuation](glossary:attenuation): the signal weakens in proportion to distance

## 2. Signal representation

### 2-1 Analog vs Digital

1. [Analog signal](glossary:analog-signal)

- A signal that changes continuously (can take infinitely many values)
- Examples: natural sounds, the human voice
- Directly affected by [noise](glossary:noise)
- Hard to recover (once it's damaged, that's it)
  ![analog signal](/static/images/network-ch3-data-transmission/analog-signal.png)

2. [Digital signal](glossary:digital-signal)

- A signal that changes in discrete steps, like a staircase
- Usually represented with two values (0 and 1, +v and -v)
- Range of values: discrete (usually 2)
- Indirectly affected by [noise](glossary:noise) ([bit errors](glossary:ber))
- Easy to recover (you only need to decide whether it's 0 or 1)
  ![digital signal](/static/images/network-ch3-data-transmission/digital-signal.png)

### Sine wave

- Why [sine waves](glossary:sine-wave) matter: because every complex signal can be decomposed into a sum of [sine waves](glossary:sine-wave)
- Every signal we process, whether a human voice, digital bits or music, is ultimately a combination of [sine waves](glossary:sine-wave)
- The 3 parameters that define a [sine wave](glossary:sine-wave)
  1. Amplitude (A)
     - The maximum magnitude of the signal
     - The height along the y-axis
     - Unit: volts (V)
     - "How big the swing is"
  2. Frequency (f)
     - Number of oscillations per second
     - Unit: [Hz](glossary:hertz) (Hertz)
     - The time for one oscillation = Period (T)
     - Key formula: T = 1/f
  3. Phase (φ)
     - Where within one [period](glossary:period) the signal starts

```
Amplitude ↑
        │      ╱╲
      A ┤    ╱    ╲
        │  ╱        ╲
        │╱            ╲
       0├──────────────────────→ Time
        │              ╲      ╱
     -A ┤                ╲  ╱
        │                  ╲╱
        ←──── T (period) ──→
```

- Wavelength (λ)
  - How many meters does it travel in one cycle?
  - If the signal's propagation speed is v:
    - λ = v × T

```
One cycle
      ←──── λ (wavelength) ────→
   ┌─────────────────────────────┐
   │      ╱╲              ╱╲     │
   │    ╱    ╲          ╱    ╲   │
   │  ╱        ╲      ╱        ╲ │
   │╱            ╲  ╱            │
   │               ╲╱            │
   └─────────────────────────────┘
   x-axis: distance (space)
```

## 3. Frequency Domain (frequency-domain analysis)

### 3-1 Fourier analysis

- A mathematical operation that converts a time-domain signal into the [frequency domain](glossary:frequency-domain)
  **Every signal is a sum of [sine waves](glossary:sine-wave) of various frequencies**
- The viewpoint of looking at a signal on the [frequency](glossary:frequency) axis instead of the time axis (the [bandwidth](glossary:bandwidth) graph)

```
Complex signal         Sum of sine waves

                   = 1Hz sine wave (large amplitude)
   ╱╲╱╲╱╲╱╲         + 3Hz sine wave (medium amplitude)
  ╱        ╲        + 5Hz sine wave (small amplitude)
 ╱          ╲       + 7Hz sine wave (smaller amplitude)
                    + ...
```

### 3-2 Time domain vs frequency domain

- Time graph

```
Amplitude ↑
     │  ╱╲    ╱╲╱╲
     │ ╱  ╲  ╱    ╲
     │╱    ╲╱
     ├──────────────→ Time (s)
     │
     y-axis: magnitude of the signal (amplitude)
     x-axis: time
```

- Frequency graph

```
Amplitude ↑
     │
   3 ┤ █
     │ █
   2 ┤ █     █
     │ █     █
   1 ┤ █     █     █
     │ █     █     █
     ├─────────────────→ Frequency (Hz)
       1Hz   3Hz   5Hz

     y-axis: magnitude of that frequency component
     x-axis: frequency
```

### 3-3 Spectrum and Bandwidth

- Spectrum: the range of frequencies a signal contains
- The example signal above consists of 1Hz, 3Hz and 5Hz, so [spectrum](glossary:spectrum) = 1Hz ~ 5Hz

- Absolute [Bandwidth](glossary:bandwidth) = (highest [frequency](glossary:frequency)) - (lowest [frequency](glossary:frequency)) = 5Hz - 1Hz = 4Hz
- Effective [Bandwidth](glossary:bandwidth): the narrow [frequency](glossary:frequency) range where the energy is concentrated
- In general, plain "[bandwidth](glossary:bandwidth)" means [effective bandwidth](glossary:effective-bandwidth)

```
Amplitude ↑
     │
     │  ████████
     │  ████████
     │  ████████
     │  ████████ █
     │  ████████ █  ▪
     ├─────────────────→ Frequency
        ←──────→
         effective
         bandwidth
        (most of the energy gathers here)
```

- DC (direct current) component: the 0 [Hz](glossary:hertz) component, a signal that does not change over time

### 3-4 Why these concepts matter

- [Bandwidth](glossary:bandwidth) isn't just a [frequency](glossary:frequency) range; it directly determines how much data can be sent over that medium
- Complex signal = needs many [frequency](glossary:frequency) components = needs wide [bandwidth](glossary:bandwidth)

```
Simple signal (slow changes):
   ╱╲      ╱╲
  ╱  ╲    ╱  ╲     → can be expressed with a few low frequencies → narrow bandwidth
 ╱    ╲  ╱    ╲

Complex signal (fast changes):
   ┌┐ ┌┐ ┌┐
   ││ ││ ││         → needs everything up to high frequencies → wide bandwidth
 ──┘└─┘└─┘└──
```

- Why does a [square wave](glossary:square-wave) ([digital signal](glossary:digital-signal)) have infinite [bandwidth](glossary:bandwidth)?
  - A [digital signal](glossary:digital-signal) is a [square wave](glossary:square-wave) where 0 and 1 switch abruptly at right angles
  - To build this right-angled shape from a sum of [sine waves](glossary:sine-wave), you theoretically need infinitely many frequencies
  - But in practice most of the energy is in the first few components, so it can be approximated with a finite [bandwidth](glossary:bandwidth).
  - However, the narrower the [bandwidth](glossary:bandwidth), the more rounded the shape becomes, making 0 and 1 harder to tell apart

## 4. Data Rate ↔ Bandwidth

**The larger the [bandwidth](glossary:bandwidth), the higher the [data rate](glossary:data-rate)**

```
[1] Every transmission system has only a limited frequency band
                    ↓
[2] This limit restricts the data rate that can be sent over the medium
                    ↓
[3] A square wave (digital signal) has infinitely many frequency components
   (= needs infinite bandwidth)
                    ↓
[4] But most of the energy is concentrated in the first few components
                    ↓
[5] Limiting the bandwidth distorts the signal
```

By [frequency](glossary:frequency)

```
Original (pulses before transmission):
  ┌─┐ ┌──┐ ┌─┐
  │ │ │  │ │ │
──┘ └─┘  └─┘ └──    perfect square wave


Bandwidth limited to 500Hz:
   ╱╲    ╱╲
  ╱  ╲__╱  ╲___       almost a sine wave, hard to tell 0/1 apart


Bandwidth 900Hz:
   ╱╲   ╱╲╱╲
  ╱  ╲_╱     ╲       slightly angular shape


Bandwidth 1700Hz:
   ┌╲   ┌─╲
  ╱  ╲_╱   ╲___      similar to a square wave


Bandwidth 4000Hz:
   ┌─┐  ┌──┐ ┌─┐
  ─┘ └──┘  └─┘ └──   almost the original
```

[Bandwidth](glossary:bandwidth) ∝ Data Rate (directly proportional)

Intuitive analogy
[Bandwidth](glossary:bandwidth) = number of lanes on a road
Data Rate = number of cars passing per hour

## 5. Transmission Impairments

[Analog signal](glossary:analog-signal) → degraded signal quality (a crackling radio)
[Digital signal](glossary:digital-signal) → [bit errors](glossary:ber) (0 misread as 1, 1 misread as 0)

```
Transmission Impairments
│
├─ 1. Attenuation
│
├─ 2. Delay distortion
│
└─ 3. Noise
   ├─ Thermal noise
   ├─ Intermodulation noise
   ├─ Crosstalk
   └─ Impulse noise
```

### 5-1 Attenuation

- The weakening of signal strength with distance.

1. Weakening with distance

```
Start:  ████████████  (strong)
Middle: ████████      (weaker)
End:    ████          (even weaker)
```

2. Happens differently depending on [frequency](glossary:frequency) (higher frequencies weaken faster)

```
After traveling the same distance:

Low-frequency component:  ████████  (weakened less)
Mid-frequency component:  █████     (medium)
High-frequency component: ██        (weakened a lot)
```

A [digital signal](glossary:digital-signal) is a sum of many frequencies, so if only the high frequencies weaken, the shape of the signal is ruined.
This is called **[attenuation distortion](glossary:attenuation-distortion)**.

So the receiver has 2 conditions to satisfy

1. Strong enough to be detected
2. Higher than [noise](glossary:noise)

Solutions
|Method|Role|
|---|---|
|Amplifier|Boosts the weakened signal again (for analog)|
|Repeater|Regenerates the [digital signal](glossary:digital-signal) and sends it anew|
|Loading coil|Flattens the differences in [attenuation](glossary:attenuation) across frequencies|
|Equalizer|Applies different amplification per [frequency](glossary:frequency)|

### 5-3 Delay Distortion

- Different [frequency](glossary:frequency) components arrive at different speeds
- Condition: occurs only in [guided media](glossary:guided-media) ([twisted pair](glossary:twisted-pair), [coaxial cable](glossary:coaxial-cable), fiber)
  - Does not occur in wireless (in wireless (through the air), all frequencies travel at the same speed, the speed of light)

```
Departure (simultaneous):
   Low freq  ████
   Mid freq  ████
   High freq ████  → transmit

In transit (speed difference):
   Low freq  ━→
   Mid freq  ━━→ (a bit faster)
   High freq ━━━→ (faster)

Arrival (time difference):
   Low freq  ████      ← arrives late
   Mid freq   ████
   High freq   ████    ← arrives early

   → combine into a shape different from the original
```

A **[phase](glossary:phase) difference** arises between the frequencies

The [phase](glossary:phase) difference can cause **Intersymbol Interference ([ISI](glossary:intersymbol-interference))**.

- Intersymbol Interference ([ISI](glossary:intersymbol-interference)): after one bit ends, the tail of its signal spills into the next bit and interferes with reading the next bit

```
Bit string to send: 1 0 1 1
            ┌┐ ┌┐┌┐
            ││ ││││
            ┘└─┘└┘└

After delay distortion:
            ┌┐_┌┐┌┐
             ⌒⌒⌒⌒⌒⌒  ← the end of one bit leaks into the next bit

                → bit boundaries blur → hard to tell 0/1
```

### 5-4 Noise

- Unwanted signals that intrude between the transmitter and the receiver.
- [Noise](glossary:noise) is the main limiting factor on communication system performance.

- [Attenuation](glossary:attenuation) and [delay distortion](glossary:delay-distortion) can be compensated for, but [noise](glossary:noise) fundamentally cannot be removed. So it is the ultimate limit of communication. The [Shannon](glossary:shannon-capacity) formula in step 6 defines exactly this limit mathematically.

- 4 kinds of [noise](glossary:noise)

1. Thermal [Noise](glossary:noise)

- Caused by the thermal motion of electrons
- Distributed evenly across all frequencies (hence also called [white noise](glossary:thermal-noise))
- Cannot be removed

2. Intermodulation [Noise](glossary:noise)

- Caused by nonlinearity in the transmitter/receiver/medium
- An ideal system produces output proportional to input (linear), but in reality there is some nonlinearity, so when two frequencies go in, new frequencies are formed

```
Input signal:   f₁ = 100Hz, f₂ = 150Hz
                  ↓ (passes through a nonlinear system)
Output signal:  f₁ = 100Hz (normal)
                f₂ = 150Hz (normal)
                + 250Hz (= f₁ + f₂) ← newly created noise
                + 50Hz  (= f₂ - f₁) ← newly created noise
                + ...
```

3. Crosstalk

- Caused by electrical coupling between adjacent lines
- The signal flowing in the neighboring wire leaks into my wire

```
Wire A: ━━━ signal A ━━━━━━━━━━
              ↕  (part of the signal leaks over through electrical coupling)
Wire B: ━━━ signal B + part of signal A ━━
```

- Solution: [shielding](glossary:shielding). This is why [UTP](glossary:utp) is more expensive than [STP](glossary:stp) but has less [crosstalk](glossary:crosstalk).

4. Impulse [Noise](glossary:noise)

- Caused by external electromagnetic [interference](glossary:interference), lightning, etc.
- Characteristics
  - Irregular short spikes
  - Short duration + high [amplitude](glossary:amplitude)
  - Non-continuous

- To the human ear it's just heard for a moment, so why is it fatal for digital signals?
  - Digital sends many bits in a short time, so even a single short spike corrupts several bits at once.

- If even one bit is different, things like images get completely garbled, yet in reality [bit errors](glossary:ber) inevitably occur. How do we manage them?

## 6. Channel Capacity

### 6-1 What is Channel Capacity?

- The maximum [data rate](glossary:data-rate) that can be transmitted over a communication channel under given conditions

```
Channel Capacity (C)
= "the maximum number of bits per second this channel can carry"
= unit: bps (bits per second)
```

- The 4 factors that determine [channel capacity](glossary:channel-capacity)

1. Data Rate
   - Unit: [bps](glossary:bit-rate)
   - Meaning: the speed you want to send at
2. [Bandwidth](glossary:bandwidth)
   - Unit: [Hz](glossary:hertz)
   - Meaning: the width of frequencies the channel passes
3. [Noise](glossary:noise)
   - Unit: [dB](glossary:decibel)
   - Meaning: the [noise](glossary:noise) level of the channel
4. Error rate
   - Unit: ratio
   - Meaning: how often errors occur

- [Bandwidth](glossary:bandwidth) ↑ → [Data rate](glossary:data-rate) ↑ (learned in step 4)
- [Bandwidth](glossary:bandwidth) ↑ → cost ↑
- [Noise](glossary:noise) ↑ → Error rate ↑ → effective [Data rate](glossary:data-rate) ↓
- [Noise](glossary:noise) is the most fundamental constraint (learned in step 5)

### 6-2 Two formulas for finding channel capacity

1. [Nyquist](glossary:nyquist-bandwidth) [Bandwidth](glossary:bandwidth)
   - How high can it go if there is no [noise](glossary:noise)?
   - The limit of an ideal noise-free channel
   - Formula: C = 2B log₂ M
     - C = [channel capacity](glossary:channel-capacity), B = [bandwidth](glossary:bandwidth), M = number of signal levels (number of distinct signal elements)
   - If M is increased to infinity, does the [data rate](glossary:data-rate) become infinite too?
     - In theory yes, but the spacing between signal levels narrows and it becomes vulnerable to [noise](glossary:noise)
     - So a real limit that accounts for [noise](glossary:noise) is needed
2. [Shannon](glossary:shannon-capacity) Capacity
   - How high can it go in the real world, with [noise](glossary:noise)?
   - The theoretical upper bound of a real channel
   - [Data rate](glossary:data-rate) ↑ → time per bit ↓ → even short [noise](glossary:noise) corrupts many bits → error rate ↑

   First, quantify the [noise](glossary:noise) level
   [SNR](glossary:snr) (Signal-to-Noise Ratio)

   ```
           signal power
   SNR = ─────────
           noise power
   ```

   Used as is, the numbers get too large or too small, so it is converted to [dB](glossary:decibel) (decibels)

   ```
   SNR_dB = 10 × log₁₀ (signal/noise)
   ```

   - [Shannon](glossary:shannon-capacity) formula
     - **C = B × log₂ (1 + [SNR](glossary:snr))**
   - [SNR](glossary:snr): [signal-to-noise ratio](glossary:snr) (a ratio, not [dB](glossary:decibel)!)
   - Large [SNR](glossary:snr) (little [noise](glossary:noise)) → log₂(1+[SNR](glossary:snr)) is large → C is large (can send a lot)
   - Small [SNR](glossary:snr) (lots of [noise](glossary:noise)) → log₂(1+[SNR](glossary:snr)) is small → C is small (can send only a little)
   - [Shannon capacity](glossary:shannon-capacity) is an unreachable theoretical upper bound

### 6-3 Which is more efficient to increase, Bandwidth or SNR?

- Capacity is linear in [bandwidth](glossary:bandwidth) and logarithmic in [SNR](glossary:snr), so in theory increasing [bandwidth](glossary:bandwidth) is more efficient.
- But in practice, increasing [SNR](glossary:snr) is easier
- So in reality, [SNR](glossary:snr) is squeezed out to the point of diminishing returns, and then B is increased.
