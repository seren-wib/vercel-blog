# 0. Course overview

- IIR 21장 중 18\~20장을 이번 학기에 다룸. 시험 범위는 ch1\~7
- **Take-away**: 단순한 IR 시스템(불리언 검색)의 설계와 자료구조 + 이번 수업에서 다룰 주제

| IIR 장 | 주제                            | 한 줄                                                                                               | 수업    |
| ------ | ------------------------------- | --------------------------------------------------------------------------------------------------- | ------- |
| 01     | 불리언 검색 (Boolean retrieval) | 역색인, 포스팅 교집합, 질의 최적화                                                                  | ch1     |
| 02     | 용어 어휘와 포스팅 리스트       | 구문 질의 `"Stanford University"`·근접 질의 `Gates near Microsoft` → 단어 위치까지 저장한 색인 필요 | ch2     |
| 03     | 사전과 오류 허용 검색           | k-gram 색인: `bo` → aboard, about, boardroom, border. 철자 틀려도 찾기                              | ch3     |
| 04     | 색인 구성                       | 큰 컬렉션은 여러 컴퓨터로 나눠 만듦 (parser → inverter, map·reduce)                                 | ch4     |
| 05     | 색인 압축                       | Zipf 법칙: log 빈도 vs log 순위가 직선                                                              | ch5     |

| 07     | 완전한 검색 시스템의 점수 계산  | 파서·색인·철자 교정·점수·순위 전체 구조                                                             | ch7     |
| 08     | 평가, 동적 요약                 |                                                                                                     | 범위 밖 |

| 13     | 텍스트 분류, Naive Bayes        | 문서를 정해진 클래스로 자동 분류 (언어, 성인물, 지역)                                               | 범위 밖 |
| 14     | 벡터 분류                       |                                                                                                     | 범위 밖 |

| 19     | 웹과 그 문제들                  | 다양한 문서·사용자, 링크 분석·사용자 데이터 활용                                                    | 범위 밖 |
