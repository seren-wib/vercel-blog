# 1. 컴퓨터과학은 무엇을 다루는가?

**컴퓨터과학은 문제 해결 방법과 이를 실행하는 컴퓨터 시스템을 함께 연구하는 학문이다**

1. 문제정의
2. 알고리즘 설계
3. 프로그램 구현
4. 컴퓨터 시스템에서 실행

## 전체 흐름 한 줄

**문제 → 알고리즘 → 프로그램(C 코드) → 실행 파일 → 프로세스 → CPU가 실행**

# 2. 문제와 알고리즘

- 알고리즘적 사고: 문제를 명확한 단계와 데이터의 형태로 바꾸는 것

## 알고리즘

- 기본조건 5개: 입력, 출력 명확성, 유한성, 실행 가능성
- 평가 기준 2개: 정확성, 효율성

### 예시(유클리드 호제법)

- gcd(m, n) = gcd(n, m mod n), n이 0이 되면 그때 m이 답.
- gcd(48,18) → (18,12) → (12,6) → (6,0) → 6

# 3. 프로그램과 컴퓨터 시스템의 연결

- C코드가 실행되기 까지: 전처리 → 컴파일 → 어셈블 → 링킹 → 실행 파일 → OS가 메모리에 적재

- 프로그램 실행 과정: 사용자 → 응용 프로그램 → 표준 라이브러리 → 운영체제 → 하드웨어
