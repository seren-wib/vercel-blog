## 프로젝트

### [Online Code Editor](https://github.com/seren-wib/opensource-web-azas)

브라우저에서 코드를 작성하고 실행하고 저장하는 온라인 코드 에디터. 4인 팀 프로젝트이고 프론트엔드 대부분을 맡았습니다.
React, Vite, Monaco Editor에 Express + MySQL 백엔드를 붙였고, 코드는 언어별 Docker 컨테이너에서 실행됩니다.
모든 PR이 GitHub Actions CI(Jest, Supertest, Vitest, MySQL 서비스 컨테이너)를 거치고, `main`은 보호 규칙이 걸려 있어

### [kibotos.dev](https://github.com/seren-wib/vercel-blog)

이 블로그. Vercel 위의 Next.js 15, Contentlayer, Tailwind CSS로 만들었고, 수업 노트를 글로 옮기는 발행 파이프라인이 있습니다.
모든 변경은 PR로 올라가고 CI에서 lint, 타입 검사, 빌드를 통과해야 반영됩니다.

### [SCPC 2026 AI Agent Harness](https://github.com/seren-wib/scpc-2026-agent-harness)

SCPC 2026 예선(DACON) 제출물로, 개인 기기 에이전트가 요청을 어떻게 처리할지 판단하는 규칙 기반 하네스입니다.

### [Atlas Odyssey](https://github.com/seren-wib/atlas-odyssey)

배운 것을 지도처럼 펼쳐 놓고 남은 것을 보여 주는 개인 학습 아틀라스. 2026 CUVIC 바이브 코딩 대회 개인 출품작입니다(진행 중).
AI 에이전트 주도 개발을 위해 `develop`/`main` 보호 룰셋, PR 전용 머지, 테스트 우선 흐름으로 레포를 구성했습니다.
