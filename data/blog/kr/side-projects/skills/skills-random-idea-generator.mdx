> 기술 목록에서 무작위로 몇 개를 뽑고, 그 조합으로 Claude와 프로젝트 아이디어를 내는 Claude 스킬 **random-idea**를 만든 기록. 레포는 [seren-wib/random-idea-generator](https://github.com/seren-wib/random-idea-generator)

## 1. 왜 만들었나

- 사이드 프로젝트 아이디어는 늘 이미 아는 기술에서 출발함. 그러면 새로 손대 보는 기술이 거의 안 생김
- 그래서 내 기술 목록에서 **무작위로 몇 개를 뽑고**, 그 조합으로 Claude와 아이디어를 내 보고 싶었음
- 문제는 모델한테 "랜덤으로 골라"를 맡기면 진짜 랜덤이 아니라는 것. React, Docker, PostgreSQL처럼 이미 익숙한 이름으로 계속 쏠림
- 그러면 뽑기는 스크립트가 하고, Claude는 뽑힌 결과로 아이디어만 내면 됨

### 비슷한 도구가 있나

만들기 전에 찾아본 것들 (2026-11-17 기준)

- **StackRoulette** (⭐12): 웹 스택만 다루고, 2023-02 이후 멈춰 있음
- **random-stack 류 레포**: 별 0~2개짜리 작은 레포들
- **Hack Club What Should I Build?**, **onemillionideas**: 프로젝트 아이디어를 보여주는 사이트
- **IdeaXApi**, **Pickproject**: 아이디어 생성에 LLM을 붙인 형태
- **분야별 개수를 정해서 뽑는 것**("AI 하나, 하드웨어 하나, 프론트엔드 둘")은 못 찾았음. 그래서 직접 만들기로 함

## 2. 만든 것

- Claude 스킬이자 Claude Code 플러그인 `random-idea`. 공개 레포, MIT 라이선스, v0.1.0
- Node 18 이상, 의존성 0. Windows, macOS, Linux에서 돎

### 기술 목록

- `skills/random-idea/assets/techs.json`에 기술 **2,763개**, 분야 **17종**

### 뽑기: `scripts/pick.mjs`

- 시드가 있는 난수 생성기 **mulberry32**로 뽑음. 같은 시드면 어느 컴퓨터, 어느 Node 버전에서도 같은 결과가 나옴
- 결과는 Markdown 표와 시드 한 줄. 시드를 다시 넣으면 같은 추첨을 반복할 수 있음

```bash
node scripts/pick.mjs [options]
```

| 옵션                          | 하는 일                                              |
| ----------------------------- | ---------------------------------------------------- |
| `-n`, `--count N`             | 전체에서 N개 뽑기. 기본 4                            |
| `--from "AI/ML=1,Frontend=2"` | 분야별로 개수를 정해 뽑기. 분야 이름은 대소문자 무시 |
| `--seed S`                    | 예전 추첨 반복                                       |
| `--categories`                | 분야와 분야별 개수 보기                              |
| `-h`, `--help`                | 옵션 보기                                            |

- `-n`과 `--from`은 같이 못 씀

### Claude가 하는 일

1. 요청 문장("AI 하나, 하드웨어 하나로 아이디어 줘")을 옵션으로 바꿔서 `pick.mjs`를 실행
2. 뽑힌 표와 시드를 보여줌
3. 아이디어 3개를 냄. 아이디어마다 뽑힌 기술을 어디에 쓰는지, 주말에 끝낼 수 있는 가장 작은 버전, 가장 막힐 것 같은 부분

- **바꿔치기 금지.** 조합이 어색해 보여도 뽑힌 기술을 하나도 빼거나 다른 걸로 바꾸지 않게 스킬에 적어 둠. 데이터베이스나 호스팅처럼 따로 필요한 건 "also needed" 줄로 분리
- **목록은 대화에 안 읽힘.** 500 KB짜리 `techs.json`은 스크립트만 읽고, 대화에는 뽑힌 줄만 들어감. 그래서 한 번 뽑는 데 토큰 몇백 개면 됨

### 설치

Claude Code에서 마켓플레이스를 추가하고 플러그인을 설치

```bash
claude plugin marketplace add seren-wib/random-idea-generator
```

```bash
claude plugin install random-idea@seren-wib
```

- 새 세션을 열거나 열린 세션에서 `/reload-plugins`
- 스킬이 `node`를 실행하므로 터미널에서 `node --version`이 돼야 함

## 3. 만들면서 바뀐 결정

- **웹페이지 없이 CLI로.** 뽑기 화면은 만들지 않음. 아이디어는 어차피 Claude와 대화하면서 냄
- **CLI 레포 대신 스킬 하나로.** 따로 설치하는 CLI 도구 대신 스킬 폴더 하나(`SKILL.md`, 스크립트, 목록)에 다 넣음
- **아는 정도(known) 칸은 뺌.** 기술마다 아는지 표시해서 아는 것과 모르는 것의 비율로 뽑는 칸을 넣으려다 뺐음
- **private → 공개, 영어로.** 처음엔 private 레포였다가 공개로 바꾸고, README와 목록을 영어로 씀
