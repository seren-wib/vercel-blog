## Projects

### [Online Code Editor](https://github.com/seren-wib/opensource-web-azas)

A browser-based code editor where users write, run and save code, built by a team of four (I built most of the front end).
React, Vite and Monaco Editor on an Express + MySQL back end, with code running in per-language Docker containers.
Every pull request runs through GitHub Actions CI (Jest, Supertest, Vitest, MySQL service container), and `main` is
protected so nothing merges until it passes.

### [kibotos.dev](https://github.com/seren-wib/vercel-blog)

This blog, built with Next.js 15, Contentlayer and Tailwind CSS on Vercel, plus a pipeline that turns course notes into posts.
Every change ships through a pull request with lint, type check and build in CI.

### [SCPC 2026 AI Agent Harness](https://github.com/seren-wib/scpc-2026-agent-harness)

A rule-based harness for the SCPC 2026 qualifier (DACON) that decides how a personal-device agent should handle a request,
written in plain Python with no dependencies. Final score **0.8408** (baseline 0.5206).

### [Coffee Shop](https://github.com/seren-wib/coffee-shop)

A coffee-bean online shop for the Software Engineering term project (in progress), built by a team of three.
I build the React + Vite front end on top of a Django back end.

### [Atlas Odyssey](https://github.com/seren-wib/atlas-odyssey)

A personal learning atlas that maps what I've learned and shows what's left, my solo entry for the 2026 CUVIC Vibe Coding
Contest (in progress). The repo is set up for AI-agent-driven development: protected `develop`/`main` rulesets, PR-only
merges and a test-first workflow.

### [Amazon Price Scraper](https://github.com/seren-wib/amazon-price-scraper)

Scrapes Amazon search results through ScraperAPI, stores them in SQLite and CSV, and charts prices in a Streamlit dashboard.
