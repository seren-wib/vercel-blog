## Projects

### [kibotos.dev](https://github.com/seren-wib/vercel-blog)

This blog. Next.js 15, Contentlayer and Tailwind CSS on Vercel, with category-based navigation, per-post tables of contents,
chapter ordering and a publishing pipeline that turns course notes into posts. Every change goes through a PR with lint,
type check and build in CI.

### Online Code Editor

A browser-based code editor where users write and run code. React, Vite and Monaco Editor on the front end, Express and
MySQL with JWT authentication on the back end, code execution through the Judge0 API, tested with Jest, Supertest and Vitest.

### HTCondor Cluster on Apple Silicon

Three KVM virtual machines on an Apple Silicon Mac, networked into an HTCondor cluster that schedules and runs batch jobs.
Written up in [HW2](/blog/cloud-computing/cloud-computing-hw2-kvm-vm-cluster/) and [HW3](/blog/cloud-computing/cloud-computing-hw3-htcondor-cluster/).

### FastAPI CRUD API

A REST API for posts built with FastAPI, SQLAlchemy and PostgreSQL, covering request-scoped DB sessions and the full CRUD cycle.

### AI Agent Pipeline Templates

Single-agent and multi-agent (PM, backend, frontend, review) project templates for AI coding agents, built around a
test-first flow and a fixed verification order: lint, type check, unit and integration tests, build, E2E.
