# 1. What does computer science deal with?

**Computer science is the study of problem-solving methods together with the computer systems that execute them**

1. Problem definition
2. [Algorithm](glossary:algorithm) design
3. Program implementation
4. Execution on a computer system

## The whole flow in one line

**Problem → [algorithm](glossary:algorithm) → program ([C code](glossary:c)) → [executable](glossary:executable-file) → [process](glossary:process) → executed by the [CPU](glossary:cpu)**

# 2. Problems and algorithms

- [Algorithmic](glossary:algorithm) thinking: turning a problem into clear steps and data forms

## Algorithm

- 5 basic conditions: input, output, definiteness, finiteness, effectiveness
- 2 evaluation criteria: correctness, efficiency

### Example (Euclidean algorithm)

- [gcd](glossary:gcd)(m, n) = [gcd](glossary:gcd)(n, m [mod](glossary:modulo) n); when n becomes 0, m is the answer.
- [gcd](glossary:gcd)(48,18) → (18,12) → (12,6) → (6,0) → 6

# 3. Connecting programs and computer systems

- Until C code runs: [preprocessing](glossary:preprocessing) → [compiling](glossary:compiler) → [assembling](glossary:assembly) → [linking](glossary:linker) → [executable](glossary:executable-file) → [OS](glossary:os) [loads](glossary:loader) it into memory

- Program execution path: user → application program → [standard library](glossary:standard-library) → [operating system](glossary:os) → hardware

## Abstraction

Hide the complex internals and expose only what the user needs

[Address](glossary:memory-address) of [arr[i]](glossary:array) = start address + i × element size
