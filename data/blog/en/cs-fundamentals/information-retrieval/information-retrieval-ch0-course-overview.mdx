# 0. Course overview

- This semester covers 18–20 of the 21 IIR chapters. The exam covers ch1–7
- **Take-away**: the design and data structures of a simple [IR](glossary:information-retrieval) system ([Boolean retrieval](glossary:boolean-retrieval)) + the topics this course will cover
